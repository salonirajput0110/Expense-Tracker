# Personal Expense Tracker

A mobile expense and budget management application built using React Native, Expo, TypeScript and SQLite.

## Features

- Add income and expenses
- Categorize expenses
- Track total income
- Track total expenses
- Current balance
- Filter transactions by category
- Filter transactions by month
- Monthly expense summary
- Expense analytics
- Monthly budget management
- Budget warning and exceeded-budget alerts
- SQLite local storage
- Light and dark mode

## Technology Stack

- React Native
- Expo
- TypeScript
- Expo SQLite
- AsyncStorage
- Expo Router

## Project Structure

- `src/app` - Application screens
- `src/database.ts` - SQLite database
- `src/theme.tsx` - Light/Dark theme

## How to Run

Install dependencies:

npm install

Start the Expo development server:

npx expo start

The application can be tested using Expo Go on Android.
